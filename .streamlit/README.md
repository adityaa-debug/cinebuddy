# 🎬 CineBuddy: AI Movie Suggestion Chatbot

A chatbot that suggests movies based on your mood, favourite genres and language.

**Live demo:** https://cinebuddy-hkc8gdgtappjdsvveowut23.streamlit.app/

## Features
- Chat interface with conversation memory
- Sidebar to pick genres, mood and movie language
- Quick-start buttons and a clear-chat option

## Built with
Python, Streamlit, Google Gemini API

## What I learned
- Setting up a Python project with a virtual environment
- Calling an AI API and using a system prompt to shape the bot
- Keeping API keys secret and deploying an app with GitHub and Streamlit Cloud

This was my first AI project, built with help from an AI assistant. I used it to learn how each part works, and my next project will be built on my own.
